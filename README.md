## Overview

JoopJoop은 다양한 청년 정책 정보를 사용자의 프로필과 관심 분야에 맞추어 탐색하고, 정책별 조건을 보다 쉽게 확인할 수 있도록 기획한 서비스입니다.

저는 **프론트엔드 개발을 중심으로 참여**했고, 프로젝트가 진행되면서 API 연동과 일부 백엔드·AI 체크리스트 관련 로직까지 경험했습니다.

> 이 저장소는 팀 프로젝트 전체 소스코드를 복제한 저장소가 아니라, 제가 직접 담당하거나 개발에 참여한 내용을 중심으로 정리한 개인 포트폴리오입니다.

## Key Contributions

### 1. 사용자 맞춤 질문 흐름 개선

사용자가 정책 탐색에 필요한 정보를 입력할 수 있도록 카테고리별 질문 화면을 구현하고 반복적으로 개선했습니다.

고용, 금융, 주거 등 질문 유형에 맞게 입력 방식을 조정하고, 직접 입력·단위 표시·중복 질문 방지 등 실제 사용 과정에서 불편할 수 있는 부분을 수정했습니다.

### 2. 정책 탐색 및 체크리스트

정책 목록과 상세 화면을 API와 연결하고, 사용자가 정책 조건을 확인할 수 있는 체크리스트 기능을 개발했습니다.

프로젝트 후반에는 프론트엔드뿐 아니라 체크리스트 관련 백엔드 API, CRUD, 서비스 로직도 수정하면서 하나의 기능이 프론트엔드와 백엔드 사이에서 어떻게 연결되는지 경험했습니다.

### 3. 인증 및 사용자 정보 연동

로그인·회원가입 화면을 백엔드와 연결하고 사용자 프로필 정보를 전역 상태와 연동했습니다.

사용자 이름과 프로필 정보 수정 흐름을 개선하면서 화면 상태와 서버 데이터가 일관되게 유지되도록 작업했습니다.

### 4. AI 체크리스트 로직

정책 정보를 기반으로 체크리스트를 생성하는 AI 관련 로직과 프롬프트, 테스트 코드 작업에 참여했습니다.

프론트엔드 화면 구현을 넘어 정책 데이터가 가공되고 사용자에게 전달되는 전체 흐름을 이해하는 계기가 되었습니다.

## What I Learned

처음에는 화면 단위의 구현에 집중했지만, 프로젝트가 진행되면서 하나의 프론트엔드 기능이 API, 데이터 구조, 백엔드 서비스 로직과 어떻게 연결되는지 경험했습니다.

특히 사용자에게 보이는 작은 기능 하나도 여러 계층의 코드가 함께 동작해야 완성된다는 점을 배웠습니다.

이후에는 단순히 화면을 구현하는 것보다 **서비스 전체의 데이터 흐름을 이해하면서 개발하는 것**을 중요하게 생각하게 되었습니다.
